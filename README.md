# SecKatie Tap

## How do I install these formulae?

`brew install seckatie/tap/<formula>`

Or `brew tap seckatie/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "seckatie/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
